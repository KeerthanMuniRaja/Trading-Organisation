## Toward the full vision: the parts that need no owner decision

A read-only map of "the system develops itself" found where each path stops:
- **Strategies:** ideas are invented and screened daily, but only on seen history. After 25 ideas the bar is p < 0.002,
  and the best idea is at p = 0.10. Every new idea raises the bar, so nothing can pass.
- **Code:** the system never writes code itself. The furthest it goes is AUTO-05: a person's code fix to the rule bot
  becomes a canary release by itself.

  every running forward test, and the ended idea could never be registered again.
